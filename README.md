# AquaStock

## Project Overview

AquaStock is a web application developed as a
final-year university project to facilitate
inventory management and invoicing for a
mineral water production company.

## Main Features

- Dashboard for business overview
- Customer management
- Product management
- Order management
- Invoice management
- Team management

## Technologies

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Database Management: phpMyAdmin
- Development Environment: XAMPP

## Project Type

Final-Year Project (Licence in Computer Science,
Information Systems).

## Objective

To simplify business operations by centralizing
customer, product, order, and invoice management
in a web-based application.
